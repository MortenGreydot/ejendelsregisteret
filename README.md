# ejendelsregisteret

Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + ESLint.

## Kom i gang

```bash
npm run dev
```

Åbn [http://localhost:3000](http://localhost:3000).

Rediger `app/page.tsx` — siden opdateres automatisk.

## Scripts

| Kommando        | Beskrivelse                  |
| --------------- | ---------------------------- |
| `npm run dev`   | Udviklingsserver (Turbopack) |
| `npm run build` | Produktions-build            |
| `npm run start` | Kører produktions-build      |
| `npm run lint`  | ESLint                       |

## Struktur

```
app/              # App Router: layout, sider, route handlers
public/           # Statiske filer
```
